**E4多队列扩展结果（同RSEM流程8个外部队列）**

执行日期：2026年10月15日。预登记文件PREREGISTRATION_multicohort_E4.md冻结于任何评价之前；全部8个队列（CHOL 35例+7个新TCGA队列，共3269例配对患者）使用同一固定PCA_ElasticNet模型、同一训练预处理、同一内部Rel评分与同一B=2000患者bootstrap（seed 20261017）。汇总表multicohort_E4_summary.csv；各队列明细在其E4目录。

**一、来源与输入核验**

mRNA全部来自UCSC Xena HiSeqV2（log2(RSEM norm_count+1)，2017-10-13版，与主体LIHC同一Wrangling流程），miRNA全部来自GDC官方mirbase21定量文件（前体ID空间，reads_per_million_miRNA_mapped按log2(RPM+1)）。各队列3000个模型基因覆盖率均为3000/3000；内部846项miRNA全部可在每个队列评价（846/846，优于CHOL的742/846）。病例均取唯一原发肿瘤样本并按case去重；样本映射与覆盖表存各队列inputs目录。COAD的Xena HiSeqV2平台本身只含约330例HiSeq测序样本，与miRNA配对后285例，属平台划分而非数据缺失，按预登记来源规则保留。

1. **排序迁移8/8队列全部为正且区间不含0**（rho 0.366–0.587）；内部Rel与外部RMSE的Spearman在7/8队列显著为负（点估计−0.191至−0.297，区间均不含0），PRAD为0.006（区间−0.009至0.021，含0），与Pearson方向总体一致，逐队列数值见汇总表。

3. **绝对重建在各队列均不足**：mean R²全部为负（−0.306至−5.077），不能主张跨癌种替代实测。
4. 原样本点估计与bootstrap中位数分别报告；KIRC/LUAD中Rel与外部R²的rho为负且区间不含0（KIRC −0.278、LUAD −0.116），反映高表达高分项的幅度失真在R²上的反向效应，与Pearson排序迁移并存，分别呈现，不合并解释。
5. 33项集合的可重建条目（R²>0且Pearson≥0.5）：各队列2–16/33（CHOL 16、KIRC 6、LUAD 11、COAD 6、STAD 9、PRAD 2、THCA 9、HNSC 9）。

**三、结论边界**

排序迁移从单队列观察升级为8队列同流程检验：内部质量分数对跨癌种逐miRNA误差排序具有方向一致的作用，高分子集（尤其Rel≥0.7的33项）在外部保持较高Pearson。该证据支持收窄后的表述「质量分数排序在多个同流程跨癌种队列中方向一致」，同时维持「绝对重建不足、不可替代实测、不构成临床效用」的原有边界。判定规则未按任何外部结果重选模型、权重、阈值或miRNA。

**四、配套实验：三模型生存对照（增量预后主张的判定）**

预登记PREREGISTRATION_threemodel_comparison.md（含三次运行前补记）。固定切分，惩罚Cox（alpha=0.5、五折CV、每模型固定种子），测试72例25事件，患者B=2000（seed 20261019）：

组合减mRNA的C差为+0.023，区间−0.005至0.056，**包含0；虚拟减mRNA为+0.042（−0.024至0.105），包含0**。按预登记判定规则，**增量预后价值主张删除**；真实miRNA诊断项与虚拟项接近（差+0.029，区间含零），进一步说明瓶颈表示不优于源特征。结果文件E5_threemodel_survival_comparison.csv及run_metadata。
