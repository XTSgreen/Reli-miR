# E3 下游分析结果说明

## 数据与核验

本目录的 E3 结果使用 `new/results/E0/canonical_input.rds` 中的 PCA_ElasticNet 固定切分。测试集为 **72名患者、846个 miRNA**。临床分组按 `patient_id` 与测试表达矩阵显式对齐；测试集中可归入早期组（I/II期）的患者47名，晚期组（III/IV期）18名，另有7名分期缺失或不符合预设映射。分组来源为 `stage_Early_vs_Late`。OS_status记录25个事件和47个删失个体。OS_time单位已由全部366例与GDC官方日数字段的精确匹配确认为天，来源证据见E0/public_provenance_search.md；该核对不改变既有Cox数值。

随机对照名单文件分别包含33、74、177个特征规模各 **1000份不放回随机名单**，每份名单大小及名单编号均已核验。患者bootstrap文件每种规模各有 **1000次重采样**；fast输出的随机名单bootstrap比较固定使用相应规模前200份名单。Rel、Pearson、RMSE和随机选择的同规模点结果见 `E3_subset_summary.csv` 与 `E3_random_subset_distribution.csv`；B=1000的Rel对随机比较区间见 `E3_core_patient_bootstrap_CI_fast_B1000.csv`；Rel对Pearson、RMSE及随机对照的配对差值及95%区间见 `E3_paired_comparison_bootstrap_CI.csv`。

数值核验结果为：随机名单数均为1000、每份名单大小符合目标值，fast bootstrap在33、74、177规模各有1000个有限患者相关统计量。fast模式与原bootstrap算法在相同抽样种子下的玩具和canonical B=2逐项对照均完全一致。测试矩阵846项的患者级中位相关为0.4250。

## 核心点结果

患者相关定义为：对每位患者，计算其真实与预测表达在当前 miRNA 子集上的 Pearson 相关，再对72名患者取中位数。相关矩阵误差为真实与预测样本相关矩阵非对角上三角元素的平均绝对差；值越低表示相关结构差异越小。以下值来自固定测试集点估计。

|---:|---|---:|---:|---:|
| 33 | Rel | 0.8442 | 0.1459 | 0.5327 |
| 33 | Pearson | 0.8332 | 0.1408 | 0.5380 |
| 33 | RMSE | 0.7887 | 0.1484 | 0.5590 |
| 74 | Rel | 0.7632 | 0.1786 | 0.6161 |
| 74 | Pearson | 0.7475 | 0.1778 | 0.6272 |
| 74 | RMSE | 0.7161 | 0.1961 | 0.6236 |
| 177 | Rel | 0.6717 | 0.2095 | 0.6888 |
| 177 | Pearson | 0.6684 | 0.2091 | 0.6929 |
| 177 | RMSE | 0.6027 | 0.2187 | 0.7021 |

Rel相对1000份等规模随机名单的患者相关中位数差分别为 **0.4008、0.3269、0.2421**，患者bootstrap的95%百分位区间分别为 **[0.3613, 0.4265]、[0.2975, 0.3493]、[0.2102, 0.2657]**。Rel相对随机名单的相关矩阵误差改善量定义为“随机名单误差减Rel误差”，分别为 **0.0952、0.0601、0.0308**，区间为 **[0.0832, 0.1303]、[0.0540, 0.0913]、[0.0237, 0.0555]**。所有区间均条件于固定的200份随机名单与固定评分排序，患者重采样反映测试患者抽样的不确定性；1000份随机名单之间的分布则反映特征选择变化，两类变异分别保存。

点估计显示Rel在三种规模下的患者相关均高于Pearson及RMSE选择；对应患者bootstrap区间中，Rel相对Pearson的区间均覆盖0，相对RMSE的患者相关差区间均高于0。网络误差方面，Rel与Pearson选择的差异区间均覆盖0；Rel相对RMSE选择仅在74项规模的改善区间高于0。数据支持Rel子集优于同规模随机选择的两项核心指标；其相对简单评分的优势依指标和规模而异，不能概括为普遍下游增益。

1000份随机子集的分布中，患者相关中位数的5%、50%、95%分位数在33、74、177项规模分别为 **0.3659/0.4454/0.5157、0.3903/0.4362/0.4829、0.3987/0.4300/0.4604**；相关矩阵平均绝对差相应为 **0.2167/0.2390/0.2687、0.2257/0.2402/0.2558、0.2321/0.2406/0.2504**。随机名单分位数描述的是固定测试患者下的特征选择分布，不是患者置信区间。

## 其他下游指标

差异表达分析按同一训练标准化尺度计算早期与晚期组均值差（晚期减早期），Welch t检验的BH校正范围限定在各自实际评价的miRNA子集。Rel子集的真实与预测效应相关在33、74、177项规模分别为0.8512、0.8287、0.7464，预测对真实效应的回归斜率分别为0.6134、0.5689、0.5034。按绝对标准化均值差排序的top-10重叠率为0.60、0.30、0.30，top-20为0.90、0.50、0.35。**33项规模的top-50重叠率记为NA**，因为集合大小不大于50，无法构成非退化比较；没有把原稿中由 `min(50, 33)` 导致的必然全重叠记作证据。全量及各筛选集合的结果保存在 `E3_subset_summary.csv`，逐miRNA值保存在对应 `E3_detail_*.csv`。

Cox分析对真实和预测的训练z尺度表达分别拟合单变量Cox模型，系数解释为每增加一个训练集标准差对应的logHR；不再按测试集真实值和预测值分别重新标准化。Rel子集真实与预测logHR相关在33、74、177项规模分别为0.8953、0.8441、0.4828。事件数、删失数及逐miRNA拟合情况在detail文件中；OS_time单位为天；该描述性一致性分析不证明独立预后效用。

方差、均值偏差及校准斜率显示筛选子集仍存在幅度收缩和偏差。例如Rel的平均方差比在33、74、177项规模分别为0.5223、0.4480、0.3829。相关矩阵相关系数较高不能替代对相关矩阵绝对误差的检查。聚类ARI/NMI按每个集合分别计算k=2至6，所有k值见 `E3_cluster_ARI_NMI.csv`；不同k及不同规模并非单调改善。PCA共同投影及Procrustes指标见 `E3_PCA_metrics.csv`。本分析不把相关矩阵边视作独立样本，因此不报告边级普通相关p值。

## 与原稿分析口径的差异

1. **top-50指标修正。** 原代码使用`min(50, 子集大小)`，在33项子集上等于比较全部33项与全部33项，重叠率必为1。修订分析要求集合大小严格大于k；33项集合的top-50结果为NA，top-10和top-20仍可计算。
2. **差异表达效应命名与尺度。** 原代码把组均值差命名为logFC，但实际矩阵为按训练集参数标准化的表达。此处报告晚期减早期的共同训练z尺度均值差，并补充预测效应对真实效应的斜率；不将其解释为对数倍数变化。top重叠按绝对效应排序，BH p值作为独立列报告。
3. **Cox效应单位统一。** 原流程在测试集上分别对真实和预测表达按各自标准差重新标准化后拟合Cox。此处直接使用同一模型输出中已经按训练参数标准化的真实与预测矩阵，使系数单位均为每训练集标准差，避免两边采用不同测试尺度。
4. **患者相关方向明确。** 本报告的核心相关是每名患者跨入选miRNA计算真实与预测向量相关，再取患者中位数；数值与跨患者逐miRNA相关的中位数不同。全量测试矩阵该患者级数值为0.4250。
5. **不确定性分开呈现。** 患者bootstrap以患者为抽样单位，对真实和预测矩阵同步重采样，B=1000；随机子集分布来自1000份不同miRNA名单。bootstrap区间不把随机名单当作患者样本，也不把随机子集数当作独立患者实验。Rel对Pearson/RMSE的差值区间与Rel对固定200份随机名单的差值区间采用相同的患者重采样序列。

## 文件索引与结论边界

`E3_subset_summary.csv`保存Rel、Pearson、RMSE、All及Rel阈值集的点指标；`E3_random_subset_distribution.csv`保存1000份随机名单的全指标；`E3_random_lists_m*.csv`保存随机特征名单；`E3_core_patient_bootstrap_fast_B1000.csv`与`E3_core_patient_bootstrap_CI_fast_B1000.csv`保存Rel对随机子集的患者bootstrap结果；`E3_paired_comparison_bootstrap_CI.csv`保存Rel对Pearson、RMSE及随机列表的配对差异区间；`E3_cluster_ARI_NMI.csv`、`E3_PCA_metrics.csv`和`E3_detail_*.csv`保存聚类、PCA及逐miRNA结果。

结果支持的结论限定为：在这一个固定测试切分中，Rel排序选出的33、74、177项子集在患者级相关和相关网络误差上优于等规模随机名单；Rel与Pearson的下游差异较小且区间覆盖0，Rel相对RMSE的表现因指标而异。单一测试切分、同一队列和观察性生存分析不能建立跨队列稳定性、因果机制或临床效用。

## 配对 bootstrap 复现

`new/code/downstream_paired_comparison.R`保存了生成`E3_paired_comparison_bootstrap_CI.csv`的完整计算。脚本读取固定切分的`canonical_input.rds`，按Rel、Pearson降序及RMSE升序并以miRNA名称打破并列，重建33、74、177项名单；每个规模读取`E3_random_lists_m*.csv`中random_id最小的200份既有随机名单，不重新抽取名单。每个规模的患者bootstrap种子为`20261014 + m`，每次从72名测试患者中有放回抽取72行，并对真实和预测矩阵同步重采样。患者相关先按每名患者跨当前名单计算，再取患者中位数；网络误差是重采样患者上的相关矩阵非对角上三角绝对差均值。脚本报告Rel减Pearson/RMSE/随机名单的患者相关差，以及对照或随机名单网络误差减Rel网络误差；点估计来自原始72名患者，95%区间为1000次配对bootstrap差值的2.5%和97.5%分位数。

从项目根目录可复现正式CSV：

```powershell
Rscript new/code/downstream_paired_comparison.R new/results/E0/canonical_input.rds new/results/E3 new/results/E3_paired_comparison_bootstrap_CI.csv 1000
```

运行前若目标CSV已存在，脚本会先读取它，校验18项点估计；当`B=1000`时，还会校验bootstrap均值和两端区间，只有全部匹配后才写入目标文件。小样本检查可将最后一个参数改为`2`并把输出路径改到临时文件；例如：

```powershell
Rscript new/code/downstream_paired_comparison.R new/results/E0/canonical_input.rds new/results/E3 new/results/_sanity/E3/paired_B2.csv 2
```

已执行B=2检查及正式B=1000独立复算；后者18项点估计最大绝对差为`7.01e-16`，bootstrap均值及95%区间最大绝对差均为0。临时复算结果保存在`new/results/_sanity/E3/paired_B1000_recheck.csv`，未覆盖正式结果文件。
